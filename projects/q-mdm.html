Q-MDM.

Shared memory for independent agents

Q-MDM stores memory outside any single agent. A second agent can inspect the source behind a decision, retrieve the version it needs, and continue a task without replaying the full conversation.

01 / Project notes

How it works

The memory service keeps messages, decisions, procedures, revisions, and checkpoints as explicit records. Agents access the same service through MCP or REST, retrieve compact memory handles, and expand exact source versions when needed.

02 / Project notes

The research

The project also explores graph-based and quantum-inspired retrieval. The quantum-walk component is a numerical simulation on ordinary hardware. The recorded synthetic comparison has not established a quality advantage over simpler graph methods.
