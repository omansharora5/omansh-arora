RL Environment for Semiconductor Yield.

Fab Yield Agent

Fab Yield Agent gives an agent a semiconductor process to investigate and a budget of twelve experiments. It must use yield and defect observations to decide which process change is worth trying next.

01 / Project notes

The environment

The agent changes simulated process parameters, observes the result, tests a bottleneck hypothesis, and submits a process recipe. The reward considers yield, efficiency, causal attribution, and stability.

02 / Project notes

Training and evaluation

The project includes a Qwen2.5-7B training workflow using GRPO. It was built for the Meta Open Environment hackathon. The environment is a simulation; its results are not measurements from a physical semiconductor fab.
