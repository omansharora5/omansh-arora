Quantum-inspired memory

I want an agent to remember more than the words closest to its question. A useful memory may sit a few relationships away, behind a decision or an earlier event. Q-MDM is where I am testing that idea.

Omansh AroraUpdated 1 November 2026
The question

Does a quantum-inspired walk retrieve useful evidence that simpler graph methods miss?

01 / Idea

The working idea

A memory is a node with a source, time, and relationships. On a small candidate graph, a numerical quantum walk evolves complex amplitudes across those connections. The squared magnitudes become retrieval scores. This is a classical simulation on ordinary hardware.

02 / Current process

Where the work stands

Q-MDM already has a shared memory service, versioned records, source expansion, and retrieval traces. The current quantum-walk strategy runs on a bounded graph using NumPy. In the recorded synthetic comparison, graph methods tied on retrieval quality. I have not established a quantum-walk advantage.

03 / Next experiment

What I want to test next

Test on less curated graphs with indirect cues, stale facts, contradictions, and missing answers. Compare lexical search, personalized PageRank, PACE, and quantum-walk retrieval at the same context budget. Report retrieval quality and computation time separately.

Scope & limits

The quantum part is a mathematical model. There is no quantum processor or demonstrated speedup. The diagram below explains retrieval; it is not a live benchmark.
